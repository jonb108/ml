VB Message Library Admin

This administrative site is only for special moderators of the VB Message Library not the public.

Deleting Messages

Search for a keyword. See the list of messages. Check one or more of the messages (click on the little square or the date). Click on Delete Checked Messages.

Editing A Message

Search for a keyword. See the list of messages. Click on the message itself. See the dialog with the date, message, brigade name, city, and state. Change whatever you wish. Click on Submit.

Deleting Topics

Click on Topics. See the list of Topics. Check one or more topics by clicking on the little squares - NOT on the topic description. Click on Delete Checked Topics.

Editing a Topic

Click on Topics. See the list of Topics. Click on one of the topic descriptions. See the dialog with the topic description. Edit it however you wish. Click on Submit.

Regeneration

To ensure that the topics and counts are accurate you can click on Regen. This will tidy things up.

Viewing the normal VB Message Library

You can click on the title at the top (VB Message Library Admin) and you will see the normal public VB Message Library site.
